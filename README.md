## 🧭 Overview
Read-only Git hygiene check for accidentally tracked ignored files.

## ✨ Features
- ✨ git workflow
- ✨ gitignore workflow
- ✨ developer tools workflow
- ✨ python workflow

## 🎬 Demo
Run locally with your own input. No hosted demo is currently provided.

## 🚀 Quick Start
~~~bash
git clone https://github.com/CyberLoop-dev/gitignore-audit.git
cd gitignore-audit
python main.py --help
~~~
Python 3.10+; standard library only.
